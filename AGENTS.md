# Bibliothèques partagées de Dupla

- Utilise `DuplaDesign` comme source commune des couleurs, typographies, styles et composants SwiftUI pour les apps de la suite.
- Avant d’ajouter un composant d’interface, évalue s’il pourrait servir à plusieurs écrans ou apps. Place les composants génériques et leurs variantes réutilisables dans `DuplaDesign`. Garde la logique métier et les compositions propres à une fonctionnalité dans l’app.
- Vérifie les changements du package en ligne de commande. Valentin fait les essais manuels dans les apps de la suite.
- Ajoute ou mets à jour une preview Xcode pour chaque composant d’interface créé ou modifié. Montre les variantes et les états utiles à la comparaison.

## Skill SwiftUI

- Pour toute création, modification ou revue de code SwiftUI, utilise le skill `dupla-swiftui`. Lis son [SKILL.md](skills/dupla-swiftui/SKILL.md) avant d’intervenir, puis uniquement les références utiles à la tâche.
